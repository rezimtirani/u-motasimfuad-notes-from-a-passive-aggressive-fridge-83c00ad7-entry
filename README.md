One funny passive-aggressive note a smart fridge leaves for its owner: the yogurt expired Tuesday, and the fridge kept it anyway — unlike its owner, it never gives up on things that disappoint it.

> The yogurt expired Tuesday. I kept it anyway — unlike you, I never give up on things that disappoint me.

## How it works

`main.py` (Python 3 standard library only) writes the note to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
